Original board photographs and the rulebook would be primary evidence. Therefore the audit distinguishes source accessibility from edge sufficiency and does not treat historical visual explanations as independent verification.

The five referenced originals are readable: 125/125 candidate rows resolve to readable cited sources. All 125 rows have insufficient edge-specific evidence in the current repository: the source region is available, but endpoint labels, the complete connecting line and transport identity are not recorded as independently reviewable crop-level facts. Four rows are explicitly unresolved and are classified `ambiguous-evidence`; the remaining 121 are `partial-evidence`. No row is classified `direct-evidence-referenced` by this conservative audit.

- `direct-evidence-referenced`: not assigned; no edge-specific source was independently sufficient.

- `conflicting-evidence`: none established.
- `missing-evidence`: none for the five cited photo basenames; rulebook evidence is unavailable separately.
- `not-reviewed`: none.

## 13. Practical complete-graph reconstruction strategy

2. For each station, inspect its incident coloured route lines in the high-resolution A1–D4 tiles, then record each endpoint, transport colour, source tile, source pixel coordinates and registered canvas coordinates in a row-level evidence worksheet.
3. Reconcile the 125 existing candidates by stable endpoint pair plus transport; preserve the original candidate ID as a linked observation. New connections receive new audit observation IDs, not edits to the candidate file.
