# Station coordinate quality

Assigned coordinates use the existing calibrated 1350×1000 canvas and are normalized as `x/1350`, `y/1000`. The six identity-assigned coordinates are finite and in range. Candidate physical-marker coordinates remain in `candidate_marker_inventory.json`; they are not station identities.

Coordinate confidence is not uniform: the original full-board reference provides global placement, while quadrant photographs provide local refinement. The six close-ups are retained as evidence but are not independently registered by this pass.
