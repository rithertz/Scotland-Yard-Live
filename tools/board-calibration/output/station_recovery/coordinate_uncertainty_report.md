# Phase 3D.3 coordinate uncertainty report

The 16 high-resolution photographs were registered directly to the existing 1350×1000 rectified board reference using SIFT feature matches and RANSAC homographies. 16/16 expected tiles were usable. Registration metadata records match counts, inliers and each source-to-canvas transform.

The composite is diagnostic only. Fold curvature, glare and local perspective remain possible sources of displacement. Individual registered tiles and original JPEGs are retained for review. Yellow connected-component detections are physical-marker candidates, not station identities.
